# 04. 화면 명세 — 원석 큐레이터

- 문서 버전: 0.1.0
- 최종 수정일: 2026-09-11 (Asia/Seoul)
- 상태: Draft

기준 뷰포트: 기본 390×844px, 최소 너비 320px, 태블릿 768px, 데스크톱 1440px. 와이어프레임은 콘텐츠 우선순위와 상호작용을 표현하는 저충실도 ASCII 블록이며 장식적 세부는 [05-design-system.md](05-design-system.md)를 따른다. 디자인 토큰·컴포넌트 스펙은 05, API는 [07-api-specification.md](07-api-specification.md), URL/접근권한은 [02-information-architecture.md](02-information-architecture.md)를 참조한다.

## S01 랜딩/홈

- **화면 목적**: 서비스 가치 제안 전달, 첫 시작 CTA 노출.
- **URL**: `/`
- **진입 조건**: 모든 사용자(공개).

**와이어프레임 (390×844)**
```
┌───────────────────────┐
│  로고 "원석 큐레이터"      │
├───────────────────────┤
│                       │
│   히어로 일러스트/원석 이미지  │
│                       │
├───────────────────────┤
│ "당신의 바람과 기운,       │
│  인연을 잇는 원석"          │
│ 부제: 짧은 서비스 설명 1~2줄  │
├───────────────────────┤
│ [ 지금 시작하기 (Primary) ] │
├───────────────────────┤
│ 서비스 소개 3단 요약 카드      │
│ (소원/오행/관계)           │
├───────────────────────┤
│ 안전/개인정보 안내 짧은 링크   │
└───────────────────────┘
```

- **컴포넌트 계층**: `LandingHeader` > `HeroSection`(`HeroIllustration`, `Tagline`) > `PrimaryCtaButton` > `FeatureSummaryCards`(3) > `FooterLinks`(개인정보처리방침, 이용약관).
- **주요 카피**: 타이틀 "당신의 바람과 기운, 인연을 잇는 원석", CTA "지금 시작하기".
- **Primary CTA**: "지금 시작하기" → S02 이동(진입 시 세션 없으면 `POST /sessions` 선행 호출).
- **Secondary CTA**: 없음(하단 안내 링크는 텍스트 링크 수준).
- **입력 필드**: 없음.
- **상태**: `success`만 존재(정적 콘텐츠). `loading`은 세션 발급 API 호출 중 CTA 버튼 자체에 스피너 표시. `error`는 세션 발급 실패 시 버튼 아래 인라인 오류 메시지 + 재시도.
- **뒤로가기 동작**: 앱 최초 진입 화면이므로 브라우저 뒤로가기는 기기 기본 동작(앱 종료/이전 방문 페이지)을 따른다.
- **접근성 요구사항**: 히어로 이미지는 `alt=""`(장식용) 처리, CTA는 44×44px 이상 터치 영역과 48px 이상 높이, 포커스 순서는 로고→CTA→요약카드→푸터.
- **분석 이벤트**: `landing_view`, `landing_cta_click`.
- **연결 API**: `POST /sessions` (CTA 클릭 시, 세션 미존재 시에만).
- **수용 기준**:
  1. 320px 너비에서 가로 스크롤이 발생하지 않는다.
  2. CTA 클릭 시 세션이 없으면 세션을 발급한 뒤 S02로 이동한다.
  3. 세션 발급 실패 시 사용자에게 재시도 가능한 오류가 표시된다.

## S02 소원 선택

- **화면 목적**: 주 소원(필수) 및 보조 소원(선택) 태그 수집.
- **URL**: `/wish`
- **진입 조건**: 유효한 세션(비회원 또는 회원) 보유.

**와이어프레임 (390×844)**
```
┌───────────────────────┐
│ ← 뒤로   진행표시 1/3      │
├───────────────────────┤
│ "지금 가장 바라는 건        │
│  무엇인가요?"             │
│ 안내: 최대 2개까지 선택 가능   │
├───────────────────────┤
│ [태그칩] [태그칩] [태그칩]    │
│ [태그칩] [태그칩] [태그칩]    │
│ [태그칩] [태그칩] ...       │
│  (주 소원 선택 그리드)       │
├───────────────────────┤
│ "하나 더 고를까요? (선택)"   │
│ [태그칩] [태그칩] ...       │
│  (보조 소원 선택 그리드)      │
├───────────────────────┤
│ [ 다음 (Primary, 비활성 시 회색) ] │
└───────────────────────┘
```

- **컴포넌트 계층**: `StepHeader`(Back, ProgressIndicator) > `WishPromptText` > `WishTagGrid`(primary, single-select) > `WishTagGrid`(secondary, single-select, optional) > `PrimaryCtaButton`.
- **주요 카피**: "지금 가장 바라는 건 무엇인가요?", 보조 영역 "하나 더 고를까요? (선택)".
- **Primary CTA**: "다음" → S03 이동. 주 소원 미선택 시 비활성화.
- **Secondary CTA**: 보조 소원 칩 "선택 안 함" 초기 상태(별도 버튼 없이 미선택 자체가 허용).
- **입력 필드 및 검증 규칙**: 주 소원 1개 필수 단일 선택, 보조 소원 0~1개 단일 선택. 클라이언트에서 최대 2개(주+보조) 제약을 강제.
- **상태**: `loading`(태그 목록 조회 중 스켈레톤 칩), `empty`(태그 목록 API가 빈 배열 반환 시 "잠시 후 다시 시도해주세요" + 새로고침 CTA), `error`(목록 조회 실패 시 재시도 배너), `success`(정상 그리드).
- **뒤로가기 동작**: S01로 복귀, 선택값 폐기.
- **접근성 요구사항**: 태그칩은 `role="radiogroup"`/`role="radio"` 패턴, 키보드 화살표로 그룹 내 이동, 최소 44×44px 터치 영역, 선택 상태는 색상 외 아이콘/테두리로도 구분(색맹 대응).
- **분석 이벤트**: `wish_view`, `wish_primary_selected`, `wish_secondary_selected`, `wish_next_click`.
- **연결 API**: `GET /catalog/wishes`.
- **수용 기준**:
  1. 주 소원을 선택하기 전에는 "다음" 버튼이 비활성 상태다.
  2. 보조 소원 선택 없이도 다음 단계로 진행할 수 있다.
  3. 태그 목록 로딩 실패 시 재시도로 복구 가능하다.

## S03 마음 선택

- **화면 목적**: 현재 마음(감정 태그) 1개 수집 및 선택적 자유 입력(최대 300자) 수집.
- **URL**: `/heart`
- **진입 조건**: S02에서 주 소원 선택 완료.

**와이어프레임 (390×844)**
```
┌───────────────────────┐
│ ← 뒤로   진행표시 2/3      │
├───────────────────────┤
│ "요즘 마음과 가장 가까운      │
│  문장을 골라주세요"          │
├───────────────────────┤
│ ( ) "새로운 시작이 필요해요"  │
│ ( ) "마음이 편안해지고 싶어요" │
│ ( ) "자신감을 되찾고 싶어요"  │
│ ( ) ... (목록형 단일 선택)   │
├───────────────────────┤
│ "더 하고 싶은 말이 있다면      │
│  적어주세요 (선택, 300자)"   │
│ ┌───────────────────┐ │
│ │ [textarea]          │ │
│ └───────────────────┘ │
│                 12/300 │
├───────────────────────┤
│ [ 결과 보기 (Primary) ]    │
└───────────────────────┘
```

- **컴포넌트 계층**: `StepHeader` > `HeartPromptText` > `HeartTagList`(single-select, radio pattern) > `OptionalFreeTextArea`(counter, 300자 제한) > `PrimaryCtaButton`.
- **주요 카피**: "요즘 마음과 가장 가까운 문장을 골라주세요", 자유입력 라벨 "더 하고 싶은 말이 있다면 적어주세요 (선택)".
- **Primary CTA**: "결과 보기" → S04로 이동하며 `POST /recommendations/basic` 호출 트리거. 마음 문장 미선택 시 비활성화.
- **Secondary CTA**: 없음.
- **입력 필드 및 검증 규칙**: 마음 문장 1개 필수 단일 선택. 자유 입력은 선택, 최대 300자(클라이언트+서버 이중 검증), 제어문자 제거, 과도한 개인정보 패턴(전화번호·주민등록번호 형태 등) 감지 시 제출 전 경고([09-ai-prompts-and-safety.md](09-ai-prompts-and-safety.md#허용-정보-allowlist) 및 [12-privacy-security-compliance.md](12-privacy-security-compliance.md) 참조). 자유 입력 원문은 클라이언트에서 서버로 1회 전송되어 LLM 프롬프트 구성에만 사용되고 DB에 저장되지 않는다.
- **상태**: `loading`(제출 후 버튼 스피너, 실제 결과 로딩은 S04에서 전담), `empty`(해당 없음), `error`(자유 입력 300자 초과 시 인라인 오류, 위기 표현 감지 시 흐름 7로 라우팅), `success`(정상 입력 완료).
- **뒤로가기 동작**: S02로 복귀, 마음 선택값은 폐기되고 소원 선택값은 유지.
- **접근성 요구사항**: 라디오 목록은 키보드 위/아래로 이동, textarea는 `aria-describedby`로 글자수 카운터 연결, 300자 초과 시 `aria-invalid` 및 오류 메시지 즉시 안내.
- **분석 이벤트**: `heart_view`, `heart_selected`, `free_text_provided`(내용 미포함, boolean만), `heart_next_click`.
- **연결 API**: 직접 호출 없음(선택값은 S04에서 함께 전송).
- **수용 기준**:
  1. 마음 문장을 선택하지 않으면 "결과 보기"가 비활성 상태다.
  2. 300자를 초과하면 제출이 차단되고 오류가 표시된다.
  3. 위기 표현이 감지되면 일반 결과 대신 안전 안내로 라우팅된다(흐름 7).

## S04 추천 생성

- **화면 목적**: 규칙 엔진 실행 및 LLM 카피 생성 대기 상태 표시, 완료 시 자동 전환.
- **URL**: `/result/new` (완료 후 `/result/[recommendationId]`로 대체 이동)
- **진입 조건**: S03에서 마음 선택 완료 및 제출.

**와이어프레임 (390×844)**
```
┌───────────────────────┐
│                       │
│      로딩 애니메이션        │
│   (원석이 빛나는 모션)       │
│                       │
│ "당신에게 맞는 원석을         │
│  찾고 있어요..."           │
│                       │
└───────────────────────┘
```

- **컴포넌트 계층**: `FullScreenLoader`(`GemstoneLoadingAnimation`, `LoadingCopyText`).
- **주요 카피**: "당신에게 맞는 원석을 찾고 있어요...".
- **Primary CTA**: 없음(자동 전환).
- **Secondary CTA**: 응답이 일정 시간(`추가 검증 필요`: 임계값, 초기값 8초 제안) 이상 지연되면 "취소하고 처음으로" 텍스트 링크 노출.
- **입력 필드**: 없음.
- **상태**: `loading`(기본), `error`(API 실패 시 S03으로 복귀하며 오류 배너 표시, 입력값은 유지), `success`(즉시 S05로 리다이렉트되므로 이 화면에서 success 상태는 노출되지 않음).
- **뒤로가기 동작**: 비활성화(진행 중 이탈 방지) 또는 확인 모달 후 S03 복귀(`추가 검증 필요`: UX 라이터 최종 문구).
- **접근성 요구사항**: 로딩 애니메이션은 `prefers-reduced-motion` 시 정적 아이콘으로 대체, `aria-live="polite"`로 로딩 상태 텍스트 안내, 애니메이션에 `role="status"` 적용.
- **분석 이벤트**: `recommendation_requested`, `recommendation_generation_timeout`(임계값 초과 시).
- **연결 API**: `POST /recommendations/basic`.
- **수용 기준**:
  1. API 성공 시 자동으로 S05로 전환된다.
  2. API 실패 시 S03으로 복귀하고 이전 입력값이 보존된다.
  3. `prefers-reduced-motion` 설정 시 애니메이션이 정적 대체 콘텐츠로 전환된다.

## S05 기본 원석 결과

- **화면 목적**: 대표 원석과 AI 생성 카피(마음 요약/추천 이유/위로 문장/작은 행동) 소비, 확장 기능 진입점 제공.
- **URL**: `/result/[recommendationId]`
- **진입 조건**: `POST /recommendations/basic` 성공 직후 자동 진입, 또는 소유자의 직접 재방문.

**와이어프레임 (390×844)**
```
┌───────────────────────┐
│ ← 뒤로        공유 아이콘   │
├───────────────────────┤
│    [원석 이미지/카드]       │
│    원석 이름 (한글/영문)     │
├───────────────────────┤
│ "마음 요약"               │
│  heartSummary 텍스트      │
├───────────────────────┤
│ "추천 이유"               │
│  rationale 텍스트         │
├───────────────────────┤
│ "위로의 말"               │
│  comfortLine 1           │
│  comfortLine 2           │
│  (comfortLine 3, 선택)     │
├───────────────────────┤
│ "오늘의 작은 행동"          │
│  microAction 텍스트        │
├───────────────────────┤
│ "이 결과가 도움이 됐나요?"    │
│  ★ ★ ★ ★ ★ (1~5점)      │
├───────────────────────┤
│ [ 오행 분석 더 알아보기 CTA ] │
│ [ 관계 원석 알아보기 CTA ]   │
├───────────────────────┤
│ [ 결과 저장/로그인 텍스트링크 ] │
└───────────────────────┘
```

- **컴포넌트 계층**: `ResultHeader`(Back, ShareButton) > `StoneCard`(이미지, 이름) > `ContentSection`×4(heartSummary, rationale, comfortLines, microAction) > `FeedbackRating` > `ExpansionCtaCard`(오행) > `ExpansionCtaCard`(관계) > `SaveOrLoginLink`.
- **주요 카피**: 섹션 제목 "마음 요약", "추천 이유", "위로의 말", "오늘의 작은 행동". CTA "오행 분석 더 알아보기", "관계 원석 알아보기".
- **Primary CTA**: 오행/관계 확장 카드 2개(동급, 화면 목적상 둘 다 Primary급 확장 진입점).
- **Secondary CTA**: 공유 아이콘(S13 생성), 결과 저장/로그인 텍스트 링크.
- **입력 필드**: 만족도 별점(1~5, 필수 아님).
- **상태**: `loading`(해당 없음, S04에서 전환됨), `empty`(해당 없음), `error`(소유하지 않은 `recommendationId` 접근 시 404 전용 화면), `success`(정상 결과 표시). `usedFallback=true`인 경우에도 UI는 동일하게 `success`로 표시(사용자에게 실패 여부 노출 안 함).
- **뒤로가기 동작**: S03으로 복귀 시 새로운 추천을 다시 생성해야 함을 안내하는 확인 모달 표시(이미 생성된 결과이므로 단순 복귀 시 흐름 혼동 방지).
- **접근성 요구사항**: 각 섹션은 `<h2>` 수준 제목으로 스크린리더 탐색 가능, 별점은 키보드로 좌우 이동 및 숫자 입력 가능한 `radiogroup` 패턴, 공유 아이콘은 텍스트 라벨 대체 제공.
- **분석 이벤트**: `recommendation_view`, `feedback_submitted`, `five_elements_cta_click`, `relationship_cta_click`, `share_button_click`, `save_cta_click`.
- **연결 API**: `GET /recommendations/{id}`, `POST /recommendations/{id}/feedback`.
- **수용 기준**:

```
│ [ 보관함에 저장 (Secondary) ]│
└───────────────────────┘
```

- **컴포넌트 계층**: `ResultHeader`(Back, ShareButton) > `StoneCard`(myStone) > `StoneCard`(partnerStone, 조건부) > `StoneCard`(weStone) > `ContentSection`(conversationPrompt) > `ContentSection`(microAction) > `InviteCtaButton` > `SaveCtaButton`.
- **주요 카피**: "관계를 위한 대화 질문", "함께 해볼 작은 행동".
- **Primary CTA**: "상대방 초대하기" → 초대 링크 생성 및 공유 시트 노출.
- **Secondary CTA**: "보관함에 저장", 공유 아이콘(S13 생성, 이 경우 관계 결과 요약이 공유됨).
- **입력 필드**: 없음.
- **상태**: `loading`(해당 없음, S11에서 전환), `error`(상대방 출생정보 없이도 결과가 나와야 하므로 오류는 API 실패 시에만), `success`(정상 결과, 상대 출생정보 미제공 시 `상대의 원석` 카드는 생략 또는 별명 기반 요약만 표시).
- **뒤로가기 동작**: S05로 복귀(관계 흐름 재시작 시 S09부터 다시 진행).
- **접근성 요구사항**: 여러 원석 카드가 순차적으로 포커스 가능하도록 논리적 tab order 구성, 초대 링크 생성 후 결과(성공/실패)를 `aria-live` 영역으로 안내.
- **분석 이벤트**: `relationship_result_view`, `invite_link_created`, `save_cta_click`, `share_button_click`.
- **연결 API**: `GET /recommendations/{id}`(관계 결과 포함), `POST /recommendations/{id}/share-links`.
- **수용 기준**:
  1. 상대방 출생정보가 없어도 나의 원석과 우리의 원석은 항상 표시된다.
  2. 초대 링크는 별도 토큰으로 발급되며 원문은 1회만 노출된다.
  3. 대화 질문과 작은 행동이 모두 렌더링된다.

## S13 공유 미리보기

- **화면 목적**: 개인정보가 제거된 결과 카드를 공개적으로 노출.
- **URL**: `/share/[token]`
- **진입 조건**: 유효한(만료·철회되지 않은) 공유 토큰으로 접근.

**와이어프레임 (390×844)**
```
┌───────────────────────┐
│  로고 "원석 큐레이터"      │
├───────────────────────┤
│  [원석 카드 이미지]         │
│  원석 이름                 │
├───────────────────────┤
│  핵심 카피 요약(1~2문장)     │
├───────────────────────┤
│  [ 나도 원석 추천받기 CTA ]  │
└───────────────────────┘
```

- **컴포넌트 계층**: `PublicHeader`(로고만) > `StoneCard` > `ShareSummaryText` > `PrimaryCtaButton`(S01로 유입).
- **주요 카피**: "나도 원석 추천받기".
- **Primary CTA**: "나도 원석 추천받기" → S01 이동.
- **Secondary CTA**: 없음.
- **입력 필드**: 없음.
- **상태**: `loading`(토큰 조회 중 스켈레톤), `error`(만료·철회 시 410 상태의 "만료된 공유입니다" 화면 + S01 유도 CTA, 존재하지 않는 토큰은 404 처리), `success`(정상 카드 표시).
- **뒤로가기 동작**: 외부 유입 화면이므로 브라우저 기본 동작을 따른다.
- **접근성 요구사항**: 공개 화면이므로 SNS 미리보기 메타 태그(OG 이미지 등)는 개인정보를 포함하지 않도록 구성(`추가 검증 필요`: OG 이미지 자동 생성 파이프라인).
- **분석 이벤트**: `share_link_viewed`.
- **연결 API**: `GET /shares/{token}`.
- **수용 기준**:
  1. payload에 생년월일시, 자유 입력 원문, 상대방 별명, 세션/사용자 식별자가 포함되지 않는다.
  2. 만료된 토큰 접근 시 410 상태가 명확히 안내된다.

## S14 보관함·개인정보 설정

- **화면 목적**: 회원의 과거 결과 조회, 동의 관리, 데이터 삭제.
- **URL**: `/library`
- **진입 조건**: 로그인한 회원만 접근 가능(비회원은 로그인 화면으로 리다이렉트).

**와이어프레임 (390×844)**
```
┌───────────────────────┐
│  "보관함"    "개인정보 설정" │
│  (탭 전환)                │
├───────────────────────┤
│ [보관함 탭]                │
│  결과 카드 리스트            │
│  (썸네일 + 날짜 + 유형)      │
│  ...                     │
├───────────────────────┤
│ [개인정보 설정 탭]            │
│  동의 항목별 토글/철회 버튼    │
│  - 오행 분석 동의            │
│  - 관계 상대방 정보 동의       │
├───────────────────────┤
│  [ 전체 데이터 삭제 요청 ]    │
└───────────────────────┘
```

- **컴포넌트 계층**: `LibraryTabs`(보관함/개인정보 설정) > `RecommendationHistoryList`(카드 리스트, 무한스크롤 또는 페이지네이션) > `ConsentManagementList`(항목별 상태+철회 버튼) > `DeleteAccountSection`(확인 모달 포함).
- **주요 카피**: 탭 라벨 "보관함", "개인정보 설정". 삭제 버튼 "전체 데이터 삭제 요청".
- **Primary CTA**: 보관함 탭에서는 각 결과 카드 클릭(해당 결과 화면으로 이동). 설정 탭에서는 "전체 데이터 삭제 요청".
- **Secondary CTA**: 개별 동의 항목 "철회" 버튼.
- **입력 필드**: 삭제 확인 모달의 확인 문구 재입력 또는 체크박스(`추가 검증 필요`: 삭제 확인 UX 패턴 최종안).
- **상태**: `loading`(목록 조회 중 스켈레톤 카드), `empty`(결과 없음 시 "아직 저장된 결과가 없어요" + S01 유도 CTA), `error`(목록 조회 실패 시 재시도 배너), `success`(정상 목록).
- **뒤로가기 동작**: 이전 화면(딥링크 진입 시 S01)으로 복귀.
- **접근성 요구사항**: 탭은 `role="tablist"`/`role="tab"`/`role="tabpanel"` 패턴, 삭제 버튼은 위험 동작이므로 색상 대비와 함께 명확한 경고 텍스트 제공, 삭제 확인 모달은 포커스 트랩 적용.
- **분석 이벤트**: `library_view`, `library_tab_switch`, `consent_revoked`, `data_deletion_requested`, `data_deletion_completed`.
- **연결 API**: `GET /me/recommendations`, `DELETE /me/data`.
- **수용 기준**:
  1. 비회원이 `/library`에 접근하면 로그인 화면으로 리다이렉트된다.
  2. 전체 삭제 요청 후 확인 없이는 삭제가 실행되지 않는다.
  3. 삭제 완료 후 보관함 목록과 공유 링크 모두 접근 불가 상태가 된다.
